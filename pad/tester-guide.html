Testing the new pad

If something's not working

MetaMask says "insufficient funds" when I try to buy

You skipped step 3, or the faucet didn't reach you — go back and get test ETH first.

The page shows "devnet offline" instead of real tokens

Our test server might be down — ping the team, it usually just needs a restart.

Is any of this real money?

No. Nothing on this page, the faucet, or the token pages involves real funds. It's an isolated test network we control — the "ETH" here can't be moved anywhere real.

MetaMask is warning me about the network / asking to confirm

Normal — MetaMask always warns on a custom network it doesn't recognize. Safe to proceed, this is our own test infrastructure.
